# AltStore source

The [AltStore PAL](https://altstore.io) source for my apps. To add it in AltStore PAL, open

```
altstore://source?url=https://raw.githubusercontent.com/mjarkk/altstore-source/main/source.json
```

or paste `https://raw.githubusercontent.com/mjarkk/altstore-source/main/source.json` under Sources.
